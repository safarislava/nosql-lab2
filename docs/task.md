# Вариант №123
Доработать приложение из лабораторной работы №1. Существующие CRUD API и key-value-хранилище должны продолжать работать.

Добавить CouchDB для постоянного хранения основных объектов.

## Дополнительные параметры
- вложенные данные: **метаданные вложений**;
- связанная коллекция: **пользователи**;
- индексируемый запрос: **поиск по меткам и дате создания**;
- аналитический запрос: **среднее количество изменений объекта по состояниям**;
- изменение структуры: **замена вложенного пользователя ссылкой на отдельную коллекцию**.

## Требования к программе
+ Перенести основные объекты в назначенную документоориентированную систему, сохранив CRUD API первой лабораторной.
+ Реализовать назначенные вложенные данные и связанную коллекцию.
+ Добавить фильтрацию, сортировку, пагинацию и поиск по вложенным полям.
+ Использовать ревизии `_rev`, обработать конфликт изменений и настроить репликацию между двумя узлами.
+ Реализовать назначенный аналитический запрос с помощью MapReduce view.
+ Создать Mango-индекс и исследовать индексируемый запрос через `_explain`.
+ Настроить `validate_doc_update` и выполнить повторяемую миграцию существующих документов.
+ Сохранить key-value-хранилище первой лабораторной и использовать его для кэширования запроса к назначенной системе с TTL и инвалидацией.
